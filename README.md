One funny passive-aggressive note a smart fridge leaves its owner: dry, petty and specific — the fridge keeps score of the 2 AM visits, the leftovers have filed a complaint, and the carrots are witnesses. Running it writes the single note to /output/entry.txt.

## Run it

```sh
python3 main.py
```
